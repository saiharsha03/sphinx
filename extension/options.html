    What it does
    • Runs only on the sites saved on the phone that you allowed here, and their subdomains. It can't read any other page.
    • Your phone asks for your fingerprint every time, even when locked; approving doesn't unlock it.
    • Types an authenticator code into the field and submits its form (your fingerprint was the yes).
    • Asks as soon as a code field appears on a saved site; click the field to ask again whenever none is waiting.
    • A code that comes by text or email while it waits is offered on the phone; your fingerprint sends it, and it is typed in, never submitted.
    • When a saved site's sign-in page opens, the phone asks early; your fingerprint then covers that site's code for 60 seconds, so the code field fills at once.
    • The relay between them sees sealed blobs only.
    Timing trace

    Every hop with its time, this browser session only: the page, the ask, the relay, the phone's answer. Flags and counts, never a code or a name.
